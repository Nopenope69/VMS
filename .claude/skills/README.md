# Project skills

Copied from the owner's skill library so every Claude Code session in this repository has them.

| Skill | Use it for |
| --- | --- |
| `improve-codebase-architecture` | Scan the codebase for deepening opportunities, write a visual HTML report, then work through the one you pick |
| `codebase-design` | The shared vocabulary and principles the architecture skill uses (module, interface, depth, seam, adapter, leverage, locality) |
| `domain-modeling` | Keep `CONTEXT.md` (domain glossary) and `docs/adr/` current while designing |
| `grill-with-docs` | Interview-style design sharpening that records decisions as it goes |
| `diagnosing-bugs` | Six-phase loop for hard bugs: build a red-capable feedback loop first, then reproduce, hypothesise, instrument, fix with a regression test |

Note: `grill-with-docs` and `improve-codebase-architecture` refer to a `/grilling` primitive that is not in the
library; the grilling itself is done conversationally.
